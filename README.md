# 🌤️ ClimaxBot — Bot de Consulta Climática

O **ClimaxBot** é um bot para Telegram que permite consultar informações meteorológicas de maneira simples e rápida.

Com ele, você pode verificar as condições climáticas da sua localização atual ou pesquisar o clima de qualquer cidade.

## 🚀 Funcionalidades

- 📍 **Localização atual:** consulte o clima da região onde você está.
- 🏙️ **Pesquisa por cidade:** informe o nome de uma cidade para consultar o clima.
- 🌡️ **Temperatura:** veja a temperatura atual e a sensação térmica.
- 💧 **Umidade:** confira a umidade relativa do ar.
- 💨 **Velocidade do vento:** consulte a velocidade dos ventos.
- ☁️ **Condição climática:** saiba se está ensolarado, nublado, chovendo ou com outras condições.
- 🔄 **Novas consultas:** pesquise outras cidades sem precisar reiniciar o bot.

## 📱 Como utilizar o ClimaxBot

**1. Acesse o bot**

Abra o Telegram e entre na conversa com o ClimaxBot pelo link: https://t.me/ClimaxUnaspBot

**2. Inicie a conversa**

Envie o comando `/start` para iniciar o atendimento.

**3. Escolha como consultar o clima**

O bot apresentará duas opções:

- **📍 Compartilhar localização:** envie sua localização atual pelo Telegram. Essa opção permite consultar o clima da região onde você está.
- **✍️ Digitar outra cidade:** escolha essa opção e escreva o nome da cidade desejada, como Campinas, Santos ou Hortolândia.

**4. Confira as informações**

Após receber a localização ou identificar a cidade, o bot apresentará:

- Temperatura atual;
- Sensação térmica;
- Umidade relativa do ar;
- Velocidade do vento;
- Condição climática.

**5. Consulte outra cidade**

Depois de apresentar os dados, o ClimaxBot perguntará se você deseja consultar outra cidade.

- **✅ Sim, consultar outra cidade:** permite iniciar uma nova pesquisa.
- **❌ Não, obrigado:** encerra o atendimento.

## 🌐 Fonte das informações

Os dados meteorológicos são fornecidos pela [Open-Meteo](https://open-meteo.com/), serviço utilizado para obter informações climáticas e localizar cidades.

## 📝 Observações

- É necessário ter acesso ao Telegram para utilizar o bot.
- Para compartilhar a localização, é necessário permitir o acesso à localização no dispositivo.
- A consulta depende da disponibilidade dos serviços da Open-Meteo.
